## 用户需求
1. **优化 `generate_brand_icon` skill 的提示词规则**，消除冗余留白：当前 128×128 画布四周留 16px 边距、底托仅 84×84（约画布 65%），Chrome 工具栏以 16/32px 缩放整个画布（不裁剪），导致图标视觉尺寸明显小于其他撑满画布的扩展。
2. **保持现有图案图形完全不变**（ocean 蓝渐变 `#0071C5→#005A9E`、青色 `#00C7FD` 描边、双快进三角、feDropShadow 投影），仅修复留白/比例，重新生成 `icon.svg` 及 16/32/48/96/128 五档 PNG。

## 产品概述
Speeding 视频倍速扩展的品牌图标，用于 Chrome/Edge 工具栏与商店展示。本次产出两部分：更新后的图标生成 skill 规则文档 + 修复留白的新图标产物（SVG 源文件与各尺寸 PNG）。

## 核心功能
- **Skill 规则更新**：边距 16px→6px、底托 84×84→116×116、图标包围盒 42~46px→60~64px、右下角 24×24 Badge 区由"强制留空"改为软约束（仅中心图标避开）、黄金法则与 AI 提示词模板同步更新，并补充设计动机说明防止回归。
- **图标重生成**：图案与配色零改动，双三角以底托中心 (64,64) 为基准等比放大约 ×1.33（同时纠正原图 (68,62) 的偏心），重切 5 档 PNG 覆盖现有产物。


## 技术栈
现有项目，零新增依赖：
- SVG 矢量源：`public/icon/icon.svg`（已存在，重写）
- 位图切图：`sharp`（package.json 已装 `^0.35.3`）
- 脚本执行：`bun run`（包管理器仅允许 bun）

## 实施方案

### 1. Skill 规则优化（.codebuddy/skills/generate_brand_icon/SKILL.md）

**核心改动对照表：**

| 位置 | 现值 | 新值 |
|---|---|---|
| 全局约束·画布 | 四周留 16px 边距，右下角 24×24 留空 | 四周留 6px 安全边距；右下角 24×24 为 Badge 预留区，改为软约束（仅要求中心图标避开该区，底托可覆盖） |
| 底托占位约束 | 占画布 59%~66% | 占画布 90%~94% |
| rounded-rect | `<rect x="22" y="22" width="84" height="84" rx="10">` | `<rect x="6" y="6" width="116" height="116" rx="14">` |
| circle | `r="42"` | `r="58"` |
| hexagon | 顶点距中心 42px | 顶点距中心 58px（points 重算） |
| shield | 84×88 | 约 116×121（path 按比例重算） |
| squircle | 88×88，rx=22 | 116×116，rx=30 |
| Layer 2 图标 | 包围盒 ≤46×46px | 包围盒 ≤64×64px（≈底托 55%） |
| 黄金法则 #1 | 底托 ≈ 画布×0.618（~79px） | 底托 ≈ 画布×0.906（~116px） |
| 黄金法则 #2 | 间距数列：画布边距 16px | 间距数列：画布边距 6px |
| 黄金法则 #3 | rounded-rect rx=10 / squircle rx=22 | rx=14 / rx=30 |
| 黄金法则 #5 | 图形总面积 ≈ 画布×35% | 图形总面积 ≈ 画布×82%，底托外围仅占 ~12% |
| AI 提示词模板 | Keep 16px margin / ≤46×46 / bottom-right EMPTY | 同步更新（6px margin、≤64×64、Badge 区软约束） |

**新增"设计动机"说明**（防止未来 AI 回归生成冗余留白）：工具栏以 16/32px 缩放整个画布图片、不做内容裁剪，透明边距在缩放后按同比例保留，因此边距大小直接决定视觉占比；底托应撑满画布主体，仅保留 4~6px 抗锯齿安全边距。

### 2. icon.svg 重写（public/icon/icon.svg）

保持图案、配色、投影零改动，仅调整几何：
- 底托：`<rect x="22" y="22" width="84" height="84" rx="10">` → `<rect x="6" y="6" width="116" height="116" rx="14">`，渐变/描边/滤镜不变
- 双三角：以 (64,64) 为基准等比放大约 ×1.33（原图偏心 (68,62) 一并纠正）
- 新坐标：左三角 `(37,32) (37,96) (64,64)`；右三角 `(64,64) (64,32) (91,64)`
- 校验：图标包围盒 54×64px ≈ 底托 55%；右下角 Badge 区（x≥104, y≥104）无中心图标元素；左下角三角顶点 (37,96) 距底托边缘 26px 有余量

### 3. PNG 重切与验证

- 复用 skill 内置 sharp 流程：写临时脚本 `.output/icongen/resize.ts`（5 档尺寸，density 72，fit contain，透明背景），`bun run` 执行，覆盖 `public/icon/{16,32,48,96,128}.png`
- 验证：5 档 PNG 存在且尺寸正确；`wxt.config.ts` manifest icons 路径 `icon/{size}.png` 无需改动；Windows `start public/icon/128.png` 预览对比
