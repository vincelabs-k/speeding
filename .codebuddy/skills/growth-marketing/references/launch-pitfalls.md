# Launch Pitfalls — What to Avoid (2026 Edition)

> **基线快照：2026-08**。双层约束：2026 已失效做法 + 硬性红线。发布执行前逐条对照。

---

## 一、2026 已失效做法（曾经流行，现在反噬）

| 做法 | 为何失效 | 替代 |
|---|---|---|
| 秘密开发 + 计划好的"大揭晓" | 揭晓流量远低于预期 | 提前 Build in Public，让社区参与过程 |
| 大团队式发布（PR + 广告 + 全渠道同一天轰炸） | 风险集中一日，无后续 | 7 天预热 + 7 天窗口 + 30 天循环 |
| 48 小时内同文原样发 5 个渠道 | 算法降权 + 社区品牌损伤 | 每渠道按模板改写，错开时序 |
| 只押 Product Hunt 发布日 | PH 2026 降级为"事件"非主渠道 | 按渠道杠杆率排名分配 |
| 无明确转化事件的预发布 waitlist | 衰减极快，用户流失 | waitlist 内置转化事件或直接可用 |
| 把发布日当终点线 | 大多数失败在 post-launch loop | Day 8-30 私信/每周演示/Day 30 复盘 |
| X 上"Thread 唯一策略" | 2026 算法转向文章链接 | 文章链接 + 摘要推组合 |
| "Follow for more" CTA | 被算法降权 | 不写 CTA，内容好读者自然关注 |
| 泛 SEO 铺量 | AI Overviews 压低泛内容点击率 | 只做对比/替代/用例类深度页 |
| 多渠道同时铺开 | 5 个烂渠道 < 2 个做好渠道 | 5 项打分法选 2 渠道跑 6 周 |

## 二、硬性红线（触碰即封号/翻车）

### 社区规则红线
- **求 upvote / 多账号自顶**：HN 明令禁止，Reddit 封号
- **astroturfing**（伪装第三方/伪装有机帖自我推广）：Reddit 永久封禁
- **新账号 0 karma 发帖**：多数 subreddit auto-kill
- **错误子版块发产品帖**：被删 + 版主标记
- **48h 群发同文**（跨渠道重复）：算法降权 + 社区排斥

### 内容红线
- **营销腔词汇**：`revolutionary`、`game-changing`、`best`、`#1`、`only`——HN/Reddit 直接劝退
- **绝对化用语**：`most`、`only`、`unique`、`never been done`——与商店 listing 禁用词同源
- **定价争议话题**：主动谈价格/涨价是最快引流失败路径（Unity 定价风波、Silksong 价格争议案例）
- **截图/数据不真实**：与商店审核联动，虚假截图 = 双平台封禁

### 行为红线
- **防御性反驳**：面对批评不防御，先认同再回应
- **发布后消失**：数小时不回复评论 = 社区判定为"发帖即走"，第二次不再有机会
- **过度承诺**：承诺做不到的功能，社区记忆很长

## 三、真实案例（先导方式对比）

| 案例 | 做法 | 结果 |
|---|---|---|
| `r/freelanceUK` 产品先导帖 | 直接发产品 pitch | 封禁 365 天 |
| `r/ContractorUK` 灾难故事先导帖 | 先讲失败故事 + 学习经验 | 被接受，获得讨论 |

**结论**：先讲价值故事，别先讲产品。大众版块重"gotcha 式反驳"，小众精准版块自我推广容忍度极低。

## 四、发布前对照检查

- [ ] 目标渠道当前规则已联网校准（subreddit 版规 / Show HN 版规 / X 算法策略）？
- [ ] 非 2026 失效做法列表中的任意一项？
- [ ] 无红线行为（求 upvote / astroturfing / 0 karma 发帖 / 错误 subreddit）？
- [ ] 无营销腔与绝对化用语？
- [ ] 正文零付费、无定价争议话题？
- [ ] 截图/数据真实（与商店 listing 一致）？
- [ ] 计划了发布后 30 天的持续动作（非一日游）？
