# Positioning Framework — Targeting High-ARPU Users

> **基线快照：2026-08**。定位是分发的基础：分发放大清晰度，但无法替代它。

---

## 一、一句话定位公式

锁定定位是发布预热期的第一件事。公式：

```
For {WHO} who {PAIN}, {PRODUCT} is a {CATEGORY} that {RESULT}.
```

- `{WHO}`：具体人群，越具体越好（"网课学习者" > "学生"）
- `{PAIN}`：一个可感的痛点，含场景
- `{CATEGORY}`：熟悉的品类锚点（"浏览器扩展"）
- `{RESULT}`：可验证的结果（"自动按站点记忆你的播放速度"）

**验证标准**：一句话能否让目标人群 3 秒内判断"这和我有关"。

## 二、高 ARPU 用户画像提炼

高 ARPU 人群的共同特征（用于任何产品）：
- **时间稀缺**：愿意为省时间付费（网课党、忙碌从业者）
- **工具依赖**：已有付费工具栈，习惯为效率工具买单
- **专业背景**：能识别真实价值，反感营销腔——内容必须真诚
- **社区活跃**：在英文专业社区（Reddit/HN/IH/X）讨论工具

提炼方法：从产品真实使用场景反推 3 个画像（示例字段）：
| 字段 | 画像 A | 画像 B | 画像 C |
|---|---|---|---|
| 人群 | 网课/培训学习者 | 播客与外语学习者 | 内容创作者/研究者 |
| 痛点 | 慢速课程浪费时间 | 倍速后音调变怪难听懂 | 大量视频资料需快速过 |
| 付费倾向 | 高（教育投入） | 中高（订阅多） | 高（工具栈齐全） |
| 社区 | r/udemy、课程论坛 | r/languagelearning | 创作者社区、HN |

## 三、差异化卖点挖掘

对每个功能问三个问题，筛出真正的差异点：
1. **对比默认体验**：不装扩展时多难受？（场景对比）
2. **对比竞品**：主流方案哪里不满足？（诚实对比）
3. **反直觉点**：有什么"让我意外"的设计？（记忆点）

筛选标准：只保留同时满足「目标人群高频使用 + 竞品做不到/做不好 + 一句话讲得清」的卖点，通常 2-4 个。

## 四、价值主张句式

每卖点用统一句式（场景 + 能力 + 结果）：
```
On {SCENE} → {CAPABILITY} → {RESULT}
```
- ✅ "On Udemy-style courses → remembers each site's speed → zero setup for repeat watching"
- ❌ "Smart speed control"（只有能力）

## 五、诚实对比框架

诚实对比是英文社区信任的来源，不是示弱：
```
{竞品/默认方案} 在 {场景} 是好的，但在 {短板场景} 会 {失败表现}。
{PRODUCT} 换了个做法：{做法}，代价是 {限制}。
```
规则：不贬低竞品（Reddit 反感），只对比场景适配性；限制必须真实写。

## 六、变现路径设计（内敛表述）

以"长期可持续"为价值锚，变现路径内部设计、对外弱化：

```
免费工具（建立信任）
  → 社区口碑（自然传播，10% 规则内）
  → 持续改进（按反馈迭代）
  → 自然转化：捐赠 / Pro 版 / 可选的付费功能（被问才答，静默在落地页）
```

- 变现优先级考虑高 ARPU：小额高频（捐赠/Pro 订阅）优于广告（伤信任）
- 对外内容不主动推销付费（见 SKILL.md「付费纪律」）
- 何时可谈：IH 社区文化允许收入事实陈述；商店 listing 可展示付费版本（那是购买场景，非社区引流场景）
